## ✒️ Translation Principles

1. **Follow official Japanese conventions**
   I follow the terminology and style rules of the official Japanese translation of vanilla Minecraft (Java Edition), using full-width symbols throughout.

2. **Match the tone to the genre**
   - Industrial / scientific mods: accurate technical terminology in katakana and kanji, written in the concise plain form (*da/dearu* style)
   - Fantasy / occult mods: literary, slightly archaic phrasing that fits the world

3. **Use different registers for descriptions and explanations**
   - Descriptions (tooltips, etc.): a concise, explanatory style that states how things work
   - Explanations (guidebooks, manuals, etc.): the polite form (*desu/masu* style) so they read naturally

4. **Keep translations consistent across a series**
   The same English text gets the same Japanese text, so wording stays consistent across forks and successors (e.g. NTM NEXT → Continuum → the 1.7.10 original).

5. **No machine translation — done solo, start to finish**
   Every line is translated by hand, and I take responsibility for keeping it up to date.
