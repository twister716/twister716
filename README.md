## ✒️ 翻訳スタンス

1. **公式の日本語表記に合わせる**
   バニラ Minecraft（Java Edition）の公式日本語訳の用語・表記ルールに準拠します。記号は全角で統一します。

2. **ジャンルで文体を変える**
   - 工業・科学系：分野の専門用語に沿った正確なカタカナ・漢字表記。簡潔な「だ・である調」
   - ファンタジー・オカルト系：世界観に合わせて文語寄り・古風な言い回しを使う

3. **説明文と解説文で文体を使い分ける**
   - 説明文（ツールチップなど）：「〜する必要がある」のように、仕組みを簡潔に伝える説明調
   - 解説文（ガイドブック・マニュアルなど）：読み物として読みやすい丁寧語（です・ます調）

4. **シリーズ間で訳をそろえる**
   同じ英文には同じ訳を当て、フォークや後継 Mod（NTM NEXT → Continuum → 1.7.10 本家など）の間で表記がブレないようにしています。

5. **機械翻訳に頼らず、ひとりで最後まで**
   訳はすべて自分の手で作り、責任を持ってアップデートに追従します。
